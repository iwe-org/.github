# IWE — turn your thinking into queryable context

IWE turns a directory of markdown files into a knowledge graph you browse
from your editor and your AI agent queries from the CLI or MCP. Same files,
same links, two interfaces. No cloud, no database, no lock-in.

- **Get started** → [iwe-org/iwe](https://github.com/iwe-org/iwe) · [docs at iwe.md](https://iwe.md)
- **Editors** → [VS Code](https://github.com/iwe-org/vscode-iwe) · [Neovim](https://github.com/iwe-org/iwe.nvim) · [Zed](https://github.com/iwe-org/zed-iwe) · [Helix](https://iwe.md/docs/editors/helix/)
- **AI agents** → [MCP server](https://iwe.md/docs/agentic/mcp/) · [Claude Code skills](https://github.com/iwe-org/skills) · [memory benchmarks](https://github.com/iwe-org/memory-bench)
- **See it in action** → [a knowledge graph of 17 centuries of philosophy](https://github.com/iwe-org/seventeen-centuries)
- **Community** → [Discussions](https://github.com/iwe-org/iwe/discussions) · [r/iwe](https://www.reddit.com/r/iwe/) · [@iwe_md](https://x.com/iwe_md)

```bash
brew install iwe-org/iwe/iwe   # or: cargo install iwe iwes iwec
```
